# WiiDS 2.0

WiiDS 2.0 brings the Wii Home Menu, new menu music, more games and mods in the same app, and the fixes from the 1.26 prerelease series. The signed APK includes the channel artwork, banners, animations and music.

## Wii Home Menu

- The new channel grid uses full-tile banners for games and mods. Only the highlighted tile animates, and its channel preview stays open on the Thor’s lower screen.
- **Wii Home Menu (Dark)** uses charcoal gray with Wii-blue accents across the grid, lower channel screen, and WiiDS Settings. Pick it under **Settings → Menu Theme**. The light Wii Home Menu, classic Wii colours, and Mario Kart Wii shelf are also available.
- Updating to 2.0 selects the light Wii Home Menu and Kart Theme once. A one-time message shows where to change both. After you make a selection, WiiDS remembers it.

## New music by Noctron

- **Kart Theme** by **Noctron** is the default library track.
- **Wii Theme** by **Noctron** is available under **Settings → Menu music**, where you can also import your own tracks.
- **Are You Supposed To Be Here? (Settings Panel)** by **Noctron** is the fixed track for WiiDS Settings.

## Games, mods, and screens

- **Pokémon XD: Gale of Darkness** runs inside WiiDS. **Pokémon XG: NeXt Gen** uses StarsMmd’s 1.2.1 patch and has its own channel, settings, and saves. Import a supported USA Pokémon XD disc first. Saves from the old standalone XD app require a separate transfer.
- **Pokémon Colosseum** puts player battle status, commands, moves, targets, and supported party and item prompts on the lower screen. The upper screen holds the battle and opponent status.
- **Animal Crossing: City Folk** adds a lower-screen Wii Remote trackpad, live town map with labels, and interactive Pockets with item icons, Bells, and letters.
- **Project+** can install the official 3.2.1 pack after you import a USA Brawl revision 2 disc. Manual ZIP or SD image and Gecko code import is still available. Replacements back up the previous mod files and recover from interruptions.
- **Settings → Screen setup** lets you assign top and bottom screens, including on firmware that exposes independent attached displays. **Save Manager**, **Manage Games**, and **Game Shortcuts** now open inside WiiDS.

## Bug fixes

### Library, controls, and displays

- Fixed a startup dependency that could keep the new channels from loading when an older installation had stale disc-generated artwork. WiiDS prepares the artwork bundled with 2.0 before showing the library.
- Fixed letterboxing inside channel tiles and added higher-resolution artwork. The library footer shows the clock and date.
- Fixed Android Back handling so it opens the in-game WiiDS menu in supported games, including Super Mario Eclipse and Pokémon XG. Resume returns to the current game session.
- Fixed saved top and bottom display assignments relying on temporary display IDs. Companion touch and menu input follow the selected screen layout. Double Dash can use an available controller on an unrecognized handheld.
- Released forced refresh-rate requests on external display connections to address repeated display mode changes.
- Updated the RetroAchievements catalog cache so new entries, including Pokémon Colosseum, appear when the catalog changes.

### Pokémon XD, XG, Colosseum, and City Folk

- **XG:** Fixed the opening simulator freeze that occurred when Metagross used Bullet Punch against Gardevoir. The lower screen now uses XG’s move types and effectiveness and handles party switching and replacements after a Pokémon faints.
- **XG:** Corrected Android sound memory mapping and particle rendering. XG skips its intro logos by default.
- **XD and XG:** Fixed a move-learning crash triggered when the game read a move name or a Pokémon nickname. The reported Ledyba and Comet Punch case was covered by a regression test.
- **XD:** Fixed stale lower-screen captures in scene and fade detection, repeated rebuilds of healthy companion surfaces, waits for already-compiled shaders during cache cleanup, and repeated graphics reconfiguration while frames could still be shown. Temporary display timeouts also avoid a needless reconfiguration. Fast-forward is available under Gameplay settings.
- **Colosseum:** Fixed the lower area map staying black outside dialogue, duplicate player status panels in battle, and target labels showing positions in place of Pokémon names. The lower screen hides during supported story events and updates player status when a Pokémon levels up.
- **City Folk:** Fixed the pointer losing the last part of a swipe on release, overlapping Pockets controls, and generic labels on the lower map when the game can provide villager names.

### Setup, saves, and diagnostics

- **Super Mario Galaxy:** Setup reports completed files during long conversions and shows the active files, so the display keeps reporting progress while the cooker works. The reported device-specific setup failure is still open.
- **Retro Rewind:** Player profiles can restore a valid Mii stored in the selected driver’s save. WiiDS backs up the database and protects writes while a game is running. WiiDS can also prepare enabled compatible Riivolution packs when launching Retro Rewind.
- **Mario Kart Wii and Retro Rewind:** Added stricter validation of FaceLib archives. Mii, custom icon, and touch-layout imports now have size limits, and custom icons have image dimension limits.
- **Riivolution packs:** Removing a mod preserves its redirected saves. **Restore a removed mod** brings back the pack and its enabled state. ZIP imports validate files and only install a complete pack.
- **Diagnostics:** Exports now include game-specific panic and crash details to help identify failures such as the reported Double Dash Plus race-finish crash.

The reported Double Dash Plus race-finish crash, Galaxy white-texture issue, and intermittent Mario Kart Wii frame-rate drops remain open. XD’s rendering fixes address specific causes of stutter and flicker. Physical compatibility still varies with handheld and dock firmware.

## Install or update

Install **WiiDS-2.0-arm64.apk** on Android 11 or later. Existing WiiDS users can install it over the current app or use **Check for updates**. Let WiiDS prepare the library on the first launch. The APK includes the artwork, animations and music, so there is no separate asset download.

Supply your own supported game discs. No ROM images, personal saves or signing keys are included. **WiiDS-2.0-source.zip** contains the Android build project, native source material and build instructions. The release inventory and presentation manifest bind the published APK to its bundled assets by SHA-256.
