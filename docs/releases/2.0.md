# WiiDS 2.0

WiiDS opens to the new channel grid, with game and mod artwork, banners and animation included in the APK. The highlighted channel animates while you browse. On the AYN Thor, its preview stays open on the lower screen.

- **Wii Home Menu (Dark)** uses charcoal gray with Wii-blue accents across the grid, lower channel screen, and WiiDS Settings. Pick it under **Settings → Menu Theme**. The light Wii Home Menu, classic Wii colours, and Mario Kart Wii shelf are also available.
- **Kart Theme** and **Wii Theme** by Noctron are included. Pick a track or import your own in **Settings → Menu music**. Noctron’s **Are You Supposed To Be Here? (Settings Panel)** plays in WiiDS Settings.
- Updating to 2.0 selects the light Wii Home Menu and Kart Theme once. A one-time message shows where to change both. After you make a selection, WiiDS remembers it.
- **Save Manager**, **Manage Games**, and **Game Shortcuts** open from WiiDS. In supported games such as Super Mario Eclipse and Pokémon XG, press Back to open the WiiDS game menu.
- This release includes the dual-screen Pokémon Colosseum and Animal Crossing: City Folk work, and the Pokémon XG battle freeze and lower-screen layout fixes from the Thor previews.

## Install or update

Install **WiiDS-2.0-arm64.apk** on Android 11 or later. Existing WiiDS users can install it over the current app or use **Check for updates**. Let WiiDS prepare the library on the first launch. The APK includes the artwork, animations and music, so there is no separate asset download.

Supply your own supported game discs. No ROM images, personal saves or signing keys are included. **WiiDS-2.0-source.zip** contains the Android build project, native source material and build instructions. The release inventory and presentation manifest bind the published APK to its bundled assets by SHA-256.
