# WiiDS 1.1 artwork hotfix

The replacement 1.1 APK (Android version code 1101) includes Kaizo Mario Galaxy
Rebalanced's cover, disc and spine. These three images were present in the
developer's custom artwork folder but missing from the original downloadable
1.1 package. The bundled launcher now has all 24 images for its eight profiles.

Download 1.1 again and install it over the existing app, then reopen WiiDS.
Do not uninstall or clear app data. The corrected presentation manifest selects
a new bundled artwork folder automatically. Game imports and saves are retained.
An explicitly installed custom artwork set still takes priority over bundled art.

The hotfix retains the same application identity, signing certificate, application
code and 25 native libraries. Only the Android version code, presentation manifest,
launcher artwork metadata and three added images change inside the APK.

Release validation now rejects a presentation package missing any shipped
profile's cover, disc or spine. Local tests use the actual Kotlin installer and
artwork loader in fresh storage and over the original 1.1 presentation; image
decoding uses the host's ImageIO adapter. These are not a new on-device gameplay
pass or a clean-machine source rebuild.

The matching full source archive retains the accepted 1.1 source snapshot and
adds only the artwork, packaging checks, regression tests and this hotfix note.
For a normal source build, pass `-PwiidsVersionName=1.1 -PwiidsVersionCode=1101`.
The asset-only release rebuild can also use
`experiments/release/repackage_presentation_hotfix.py` on the original 1.1 APK,
followed by zipalign and signing with the original owner's private release key.
