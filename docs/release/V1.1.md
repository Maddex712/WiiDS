# WiiDS 1.1

## 1.1 in-app updater

**Options → Check for updates** now checks the latest WiiDS GitHub release, downloads it inside the app, and opens Android's update confirmation. Downloads continue when you leave the screen, with progress and cancellation available when you return. The APK is checked against GitHub's SHA-256 checksum, release inventory, package identity and your installed signing key before installation.

This remains **WiiDS 1.1**, with internal Android build code **1102**, on the existing release page and download link. Build-number checks allow future fixes under the same public version. The Kaizo cover, disc and spine hotfix is included.

**Already installed an earlier 1.1?** Download this APK once and install it over your existing copy to get the new updater. Do not uninstall or clear data. Future updates can be checked from inside WiiDS. Close running games and finish imports/save operations before installation; Android will ask for permission and confirmation. Reopen WiiDS after updating, then visit Check for updates to clear the completed download.

The download is the full APK. Allow about 3.7 GiB of free storage. [Update instructions and verification details](https://github.com/Maddex712/WiiDS/blob/main/docs/release/1.1-IN-APP-UPDATES.md).

Validation: actual Kotlin release-policy tests, including the live public GitHub release, passed 36 checks; save/profile gates passed 64 checks and launcher touch checks passed 47. The signed build retains all 25 native libraries and 1,477 game/menu/presentation assets from the preceding artwork hotfix. Gameplay testing limits below remain unchanged. Physical Thor testing also verified same-version detection, a complete GitHub download, leaving/returning during download, Android permission and update confirmation, cancellation recovery and download cleanup. All 27 accessible external save/settings files matched the fresh baseline; 22 permission-denied NAND system files were excluded from that comparison.

## 1.1 artwork hotfix

The 1.1 download now includes Kaizo Mario Galaxy Rebalanced’s missing cover, disc and spine. If you already downloaded 1.1, download the APK again and install it over your current copy, then reopen WiiDS. **Do not uninstall or clear app data.** Your existing game imports and saves stay in place.

This replaces the 1.1 APK under the same download link, with Android build code 1101. Game code and native libraries are unchanged. The source archive, checksums and asset inventory have also been updated. All eight profiles now have their bundled case artwork, and release checks reject a missing cover, disc or spine.

WiiDS 1.1 adds Kaizo Mario Galaxy Rebalanced, save backups and Dolphin save imports, direct game shortcuts, a RetroAchievements browser, and new Galaxy touch and picture controls. It also fixes the reproduced NSMB/MSMBWii resume crash and the missing Galaxy opening-attack color animations.

One Android app now has eight separate game/mod profiles: Mario Kart Wii, Retro Rewind, New Super Mario Bros. Wii, MSMBWii: Just a Little Adventure, Super Mario Sunshine, Super Mario Eclipse, Super Mario Galaxy, and Kaizo Mario Galaxy Rebalanced 2.1.

## New: Kaizo Mario Galaxy Rebalanced 2.1

- Adds an eighth library entry alongside original Galaxy, with its own game data, saves, settings and import state.
- Adapts the mod's native behavior and progression changes, including its event/comet tables, boss and projectile changes, hidden stars and other patched behavior.
- Builds the lower-screen maps and planet geometry from the modded files, so the companion uses the mod's stage data.
- Original Galaxy progress is not copied into Kaizo automatically. Setup starts with normal new-game progress; it does not seed the creator's optional Luigi-unlocked save.

To set it up, select Kaizo in **Options > Your games** and use **Set up Rebalanced**. You need your own clean **USA RMGE01 revision 0** Galaxy disc and the supported creator-provided Rebalanced 2.1 ZIP. The setup page provides the file picker and official download link. The mod's patch assets are not bundled in the APK.

## Save backups, export and restore

**Options > Save manager** supports all eight standard profiles.

- Create dated local backups and export them through Android's file picker.
- Restore a local backup or an exported WiiDS backup ZIP.
- Check the selected profile, file inventory, sizes and SHA-256 hashes before restoring.
- Create a verified **before restore** backup before changing existing saves.
- Recover an interrupted restore before allowing the affected game to launch.
- Keep original games and their mods separate. Galaxy's main internal save copies and external mirror are backed up together.

Close the game and any importer before using Save manager. After playing Mario Kart Wii or Retro Rewind, restart WiiDS before opening Save manager because their runtime remains in the library process. Local backups are app data; export a copy if you need to keep it outside WiiDS.

WiiDS backup ZIPs contain saves for the selected profile. Game images, account credentials, achievements, motion/controller settings, Mii data and NSMB reserve-item sidecars stay outside them. Custom NAND locations and extra NSMB NAND profiles are not supported by the shared manager.

## Import in-game saves from Dolphin

Choose the destination game in Save manager, then **Import a Dolphin save**. No root is required. WiiDS validates the file, shows a confirmation, and makes a dated **before import** backup before importing it. The selected source file is left unchanged.

| Destination | Accepted save format |
| --- | --- |
| Mario Kart Wii | `rksys.dat`, or a PAL RMCP Wii `data.bin` export |
| Retro Rewind | Its own `rksys.dat`, or a matching PAL RMCP Wii export; both RetroWFC save locations are updated while Pulsar settings are preserved |
| New Super Mario Bros. Wii | USA SMNE `wiimj2d.sav`, or its Wii `data.bin` export |
| MSMBWii | Its own USA SMNE `wiimj2d.sav`, or a matching Wii export |
| Super Mario Sunshine | USA GMSE01 seven-block game save exported as `.gci` |
| Super Mario Eclipse | GMSE04 seven-block `super_mario_sunshine` game save exported as `.gci`; mod settings are preserved |
| Super Mario Galaxy | Retail big-endian or native WiiDS `GameData.bin`, or a supported Galaxy Wii `data.bin` export |
| Kaizo Mario Galaxy | The same Galaxy containers, explicitly selected for Kaizo's separate profile |

Use Dolphin's Wii save export, copy the supported raw save, or export the individual GameCube save using Dolphin's Memory Card Manager. Imports are limited to **8 MiB**. Emulator save states, full memory-card images, complete NAND folders, general ZIP archives, GCS/SAV wrappers and unsupported game/region files are not accepted. Export from WiiDS remains WiiDS backup ZIP format.

Import replaces **all in-game slots or licenses contained in that save**. Raw Wii saves cannot reliably identify whether they came from an original game or its mod, so choose the matching destination yourself. Sunshine and Eclipse GCI identities are checked separately. Galaxy's older manual slot/quick snapshots remain available; loading one later restores the progress recorded in that snapshot.

## Galaxy controls and lower screen

- Adds **Trackpad** and **Planet** modes under **Controls > Lower screen**.
- Trackpad uses relative motion: slide to move the Star Pointer, then lift and reposition your finger without jumping the pointer elsewhere.
- Lower-screen touch and right-stick pointing share the same cursor. Touching does not automatically press A/B or shoot Star Bits.
- Planet mode retains the lower planet's drag/pinch controls.
- Shows a short lower-screen mode hint during the first five seconds of playable control. It disappears afterward, stays hidden after Home/resume, and does not appear over the title or storybook screens.
- Routes right-stick camera turns through Galaxy's own permitted left/right camera movement. The game controls elevation and camera restrictions; the previous free-orbit override has been removed.
- Galaxy settings now activate on the first tap. Dragging a press onto a different row cancels it instead of activating the wrong setting.

## Galaxy picture and color fixes

- Adds **Display > Picture** choices: **Original**, **Smooth**, and **Smooth + glow**.
- Smooth now applies neutral smoothing without forcing the old bloom and color boost. Smooth + glow keeps that optional look available. An existing Smooth selection becomes the neutral option.
- Fixes the missing color transition during the opening attack and incorrect Toad palettes by restoring material animations rejected by an obsolete address check.
- Corrects material/ambient modulation, signed diffuse lighting and distant point-light position handling.

The corrected opening attack was checked in the shared Kaizo Castle Gardens stage, and original Galaxy's Gateway was also loaded on the clean final preview. Intended warm rim lighting remains. These fixes do not claim pixel-for-pixel parity or complete rendering compatibility across every stage.

## NSMB Wii and MSMBWii

- Enables physical Thor tilt and shake by default, while preserving an explicit saved Off setting. The existing button/right-stick alternatives remain available.
- Clears stale motion state around pause and resume.
- Fixes the reproduced resume crash caused by drawing the native menu outside an active ImGui frame.
- Guards framebuffer copies when frame startup fails.
- Corrects the MSMBWii lower-screen title so it names the selected mod.

## Game shortcuts and returning to a game

- Adds **Options > Game shortcuts** for all eight games and mods, with separate identities and matching disc art where available.
- Supports direct launches from Android launchers, including Cocoon. For Cocoon, make it the default launcher, add the shortcut from WiiDS, and accept the pin request.
- Reopening the shortcut for an already-running game resumes its existing task. Mario Kart Wii and Retro Rewind now retain their game activity when returning through Home and a shortcut.
- Keeps the normal game-data readiness and profile checks for shortcut launches. Import/setup is still required before first play.
- Improves controller focus, Save manager layout and first-tap behavior.

Exiting a game returns to the WiiDS library. Automatic return to Cocoon is not included.

## RetroAchievements browser

- Browse achievement sets, descriptions, badges and existing connected-account completions.
- Groups base sets and subsets, and uses each mod's own available sets rather than substituting the original game's progress.
- Adds daily automatic refresh and a manual Refresh action.
- Downloads missing badges in parallel for faster loading.
- Shows achievement details on the lower screen while browsing the list above.

**WiiDS 1.1 does not submit new gameplay unlocks or award RetroAchievements points.** This is an achievement browser and progress viewer. The experimental earning client is not included in this release.

## Bundled menu presentation

- Fixes first-run installation of the included menu music, covers, discs and spines. The asset installer previously rejected the dotted revision label used by the bundled pack.
- Repairs missing presentation files during startup checks.
- No separate menu-art or music pack download is needed.

## Updating

1. Close the current game normally.
2. Install the signed **WiiDS 1.1 ARM64 APK** over your existing WiiDS installation. Keep application data in place; do not uninstall or clear it to update.
3. Open WiiDS and use **Options > Save manager** to create/export backups before importing or restoring progress.
4. Existing supported game imports remain required. New players should follow the [main-page setup guide](https://github.com/Maddex712/WiiDS#quick-start).

Release tag: `v1.1.0`. Android version: `1.1`, version code `1100`. The attached named source ZIP matches this release; use it together with the included build instructions and component licenses. SHA-256 checksums are provided with the release assets.

## Testing and remaining limits

- Physical Thor checks covered the eight existing game/mod profiles at selected startup, menu, gameplay or return points. The owner confirmed physical controls, NSMB tilt/shake and longer play on the development previews.
- NSMB/MSMBWii resume checks, actual NSMB backup/export/restore and document-picker import, Galaxy/Mario Kart backups, and Cocoon NSMB/Retro Rewind shortcuts passed their recorded checks.
- Galaxy checks covered file-menu pointing, Star Bit collection through lower touch, touch/stick handoff, Planet manipulation, camera restrictions, sleep/wake, Home/resume and the corrected opening-attack colors.
- The final release package contains the same **25 native libraries and 1,474 game/menu assets** as the clean physically tested dev28 preview. The release-version APK itself was not separately installed on the Thor; its version/DEX/packaging differences were checked.
- Save-adapter checks passed on the host and isolated Android storage, including all eight destinations. The production file-picker import test used NSMB's existing save; loading third-party saves in every live game is not claimed.
- One allocation failure occurred in Galaxy's selected-file menu on an earlier development build. It did not recur in the later bounded checks, including the clean final preview, but its cause is unresolved and is not claimed fixed by the color changes.
- Galaxy's lower planet is a companion view, with known model/material coverage limits. Kaizo has not received a complete boss-by-boss or stage-by-stage playthrough. Other games likewise retain their documented compatibility and performance limits.
- These checks do not establish complete-game compatibility, universal save compatibility, sustained performance in every scene, or a clean-machine source rebuild. Favorites/recent history and measured graphics/battery presets remain future work.
