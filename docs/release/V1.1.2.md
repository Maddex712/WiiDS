# WiiDS 1.1.2 — prerelease

Brawl joins the main WiiDS library, and Manage games lets you offload imported game data while keeping saves and settings.

## Changes

- Super Smash Bros. Brawl runs inside the single WiiDS APK, with its existing game menu, lower screen and Project+ support. A separate Brawl app is no longer needed for this flow.
- Brawl uses the common Your games importer, Manage games list, save-manager profile and frontend shortcut/resume handling.
- Import your own **Super Smash Bros. Brawl USA RSBE01 revision 2** disc. The importer checks its identity and exact supported executable. Brawl's lower-screen textures and fonts are built on the device from that disc.
- Corrected Brawl retail case, disc and spine artwork. Existing personal art and music overrides keep priority.
- Options > Manage games shows each game's installed state and removable size. Offloading removes imported disc/mod/map content, retaining saves, backups, settings and case art. To play again, set the game up using your own disc or mod files.
- Shared base-disc dependency checks protect Mario Kart/Retro Rewind and NSMB/MSMBWii. Offloaded MSMBWii stays off until you choose to reinstall it.
- The optional large Eclipse installer and generated Mario Kart maps are outside the APK. The combined APK is approximately 355 MB, compared with the earlier 1.85 GB build.

## Installation

ARM64 Android 11 or newer; AYN Thor is the tested device. Install this APK over your existing WiiDS installation to keep app data. **Do not uninstall WiiDS to update it.** Package: `io.github.maddex712.wiids`; version `1.1.2`, internal version code `1112`; signed with the existing WiiDS release certificate.

New Brawl setups start from its case or Options > Your games. Import only the games you want to use. Offloading game data frees storage; game runtime libraries remain in the APK. In the Thor test, offloading Brawl freed **6.71 GiB** and kept its save files, settings, HUD art and Project+ SD image.

## Validation and limits

The preceding merged preview was checked on a real Thor: Vanilla menus/character select, Project+ character select including its expanded roster, normal return to WiiDS, and same-process Home/shortcut resume. The full Brawl ISO import produced 5,319 files matching the previous disc data exactly. Common save backup/verification/restore passed on all nine Brawl save files; original owner save files were restored after testing.

The new Brawl art builder generated 583 files: 580 reference PNGs matched pixel-for-pixel and two font metadata files matched semantically. The composed logo was excluded from the pixel-parity comparison. The storage-policy checks passed 17 cases and frontend resume-selection checks passed 115 cases.

This version changes the package version metadata from the tested merged preview. The release packaging audit verifies the native libraries and assets against that preview; this versioned APK has not been separately installed for a new device acceptance pass.

Existing Project+ data was migrated and tested on the owner's device. A new on-device Project+ downloader/SD-image builder is not included in this preview. Separate add-on data is not automatically migrated by this APK. Broader Brawl gameplay, fresh-device and single-screen acceptance remain incomplete. Five unchanged Python-related core libraries still have 4 KiB ELF alignment; the three Brawl libraries use 16 KiB alignment.

**Known unresolved distribution work:** Brawl's unchanged native engine still contains the original Nintendo-byte payloads flagged in the handoff. Loading all such bytes exclusively from the player's verified disc remains unfinished. Permission to distribute BrawlRecompiled has not been recorded. This prerelease must not be described as having completed that cleanup or licensing review.
