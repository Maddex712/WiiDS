# Player profiles

Open **Options > Player profiles** for Mario Kart Wii or Retro Rewind.

- **Import existing player save:** choose the matching game's rksys.dat or supported PAL RMCP Wii data.bin. All licenses in the selected save are replaced, with a backup first. **Game save backups** opens the selected game's regular backup list.
- **Rename driver:** rename the linked Mii and matching licenses in both kart games. Saved account IDs, friend-code data, progress and ghosts stay intact. The confirmation explains this shared scope.
- **Choose driver Mii:** repair a license using an existing Mii, preserving its account and progress. Import your own Mii first through Options > Mii Data if needed.
- **Import Retro Rewind ratings:** choose RRRating.pul version 1 from the same source as the player save. Only the chosen driver's matching online profile is merged; other local ratings remain. Online login and synchronization follow the server's normal checks.

Player edits and rating imports create shared kart-players backups covering both kart saves, the shared Miis and Retro Rewind settings. Restoring one replaces both games' progress with that snapshot. Export a backup to keep it outside WiiDS. Ordinary per-game archive formats are unchanged. Close games before using these tools; interrupted transactions must recover before play resumes.
