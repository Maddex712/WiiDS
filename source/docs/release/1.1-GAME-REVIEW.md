# WiiDS 1.1 game review

October 25, 2026. Local review of the four existing base games and their existing
mod profiles. Nothing has been published. This is a bounded review, not an
all-stage compatibility, performance, audible-audio or human-motion acceptance claim.

  town's opening-attack color transition. The stale material-animation pointer
  cutoff rejected valid relocated MEM2 buffers. Clean dev28 repeats the corrected
  attack, loads original Galaxy's existing Gateway save and exits both games
  normally. All 48 accessible external files remain unchanged; task helpers are
  removed. The earlier dev21 candidate is superseded. A dev25 selected-file-menu

  baseline after dev18/dev19/dev20/dev21 installation and the final game review. Internal files are not
  included in that external-file count.
- Production backups verified for MKW, Retro Rewind, NSMB, Sunshine, Eclipse,
  Galaxy and Kaizo. MSMBWii correctly refused backup because no save exists.
- Galaxy's current internal NAND backup was exported through Android's picker
  and privately read back. All five payload sizes and SHA-256 entries match its
  manifest, including saves from all four region directories.
- Host regressions pass: 60 save archive/transaction, 62 profile/launch gate,
  68 shortcut, 93 existing-task resume and 47 launcher-touch checks.
- Paused achievement-earning work remains excluded; all 91 workbench hashes
  remain unchanged. Existing achievement-library behavior is preserved.

## Galaxy interpretation and remaining checks

The disc's post-Bowser-attack preset deliberately warms actor lighting, but the
port also dropped material animations. Dev26 records null animation lookups
despite valid palette frames. Dev27 restores real MEM2 pointers, all five Toad
palettes and the town RGB transition from 255/255/255 to 255/180/200. Physical
captures now show the pink town tint alongside varied Toad colors. Warm rim
lighting is present in the retail collection reference; pixel parity is not
claimed. The old getter fails five of eight ARM64 address cases; corrected code
passes all eight. Signed-diffuse and distant-light packing fixes also pass their
targeted regressions. No game light preset or original disc asset was changed.

The relative-touch mailbox, camera-nudge policy and actual permission methods
pass on ARM64; the old permission methods fail the regression. The actual
GamepadInput bindings/handoff pass 171 assertions, and 36 generated vertex
shader variants compile and validate. These do not replace the physical checks.

The five-second hint policy passes 19 timing/lifecycle checks. Dev19 shows no
box/label on title or storybook. Timestamped first-play captures show the hint before five seconds and hidden
afterward; Controls > Lower screen remains available. Same-PID Home/resume does
not restart it. Dev20 one-tap Controls and drag cancellation pass on Thor; the
old handler fails its regression and the correction passes nine checks.

The earlier dev18 Gateway camera capture did not record the selected stick mode;
it is not Camera-mode acceptance evidence. Explicit evidence is the dev19 check.
SDL ignores some injected controller buttons; keyboard/touch were used for those
menu checks, without replacing the owner's physical-control acceptance. Scoped
dev20 logs contain no fatal signal or Java fatal exception.
