# WiiDS 1.1

Local release candidate. Not published.

This update focuses on the four existing games and their existing mod profiles.

## Changes

- Add individual Android game and mod shortcuts through **Options > Game
  shortcuts**. Retro Rewind can launch directly from Cocoon.
- Add **Options > Save manager** for dated WiiDS save backups, export and
  restore across all eight standard game/mod profiles. Restoring first makes
  a verified backup of the current save.
- Add **Import a Dolphin save** for all eight profiles, using supported raw
  Wii saves/Wii exports and Sunshine/Eclipse GCI files. Imports validate the
  save, preserve a dated backup and use the existing restore transaction.
- Add Galaxy **Display > Picture** choices: Original, neutral Smooth, and
  optional Smooth + glow. Smoothing no longer forces added bloom/color boost.
- Add Galaxy lower-screen **Trackpad** and **Planet** touch modes. Slide to
  move the Star Pointer; lift and reposition without changing its location.
  Touch and right-stick pointing share one cursor; A/B remain separate actions.
- Show Galaxy's lower-screen mode hint only for the first five seconds of
  playable control. Its box and wording then disappear. Change modes anytime
  through **Controls > Lower screen**; Home/resume does not restart the hint.
- Route Galaxy right-stick camera nudges through the game's own permitted
  left/right turns. The game controls elevation; free orbit no longer replaces
  its camera pose or bypasses collision restrictions.
- Fix Galaxy's missing opening-attack color transition and incorrect Toad
  palettes. The town now changes color with the scene, and Toads keep their
  individual colors. Restore material animations rejected by an obsolete
  memory-address check. Correct material/ambient modulation, signed diffuse
  lighting and distant point-light positions as well.
- Enable NSMB tilt and physical shake by default while preserving an explicit
  saved Off setting.
- Add a RetroAchievements browser with base/subset grouping and each mod's own
  available sets, optional connected-account completion history, badge artwork,
  daily automatic refresh and manual Refresh. Download missing badges in parallel
  for faster browsing.
- Fix the reproduced NSMB/MSMBWii resume crash caused by drawing the native
  menu outside an active ImGui frame. Guard framebuffer copies after failed
  frame startup as well.
- Resume the existing game task when its shortcut is opened again, including
  preserving the retained Mario Kart/Retro Rewind activity stack. Improve
  save-manager layout, controller focus and first-tap behavior. Galaxy settings
  now activate on the first tap and cancel a press dragged onto another row.
- Correct the MSMBWii lower-screen title so it names the selected mod.
- Fix automatic first-run installation of the included menu music, covers,
  discs and spines. The packaged asset revision used a dotted version label
  which the installer rejected. No separate asset-pack download is required.

## Updating and using the new tools

Install the signed 1.1 APK over WiiDS; keep the application data in place.
Your supported disc imports and existing saves remain required.

For Cocoon, make it the default Android launcher, add a shortcut from WiiDS,
and accept the pin in Cocoon. Game exit returns to the WiiDS library.

Save-manager ZIPs are WiiDS backups, bound to the selected game/mod profile.
They do not include disc data, account credentials, achievements or settings.
Dolphin in-game imports accept the formats listed in [Save manager](../SAVE_MANAGER.md).
Choose the matching original/mod destination explicitly. Export remains WiiDS
backup ZIP format; emulator save states and whole NAND/memory-card images are
not imported. Custom NAND folders and extra NSMB NAND profiles remain outside
the shared manager's supported scope.

The achievement browser displays RetroAchievements sets and connected-account
progress. This release does not submit new gameplay awards to RetroAchievements;
the experimental Casual earning client remains paused.
