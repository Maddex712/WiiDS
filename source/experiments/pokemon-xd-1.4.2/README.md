# Pokemon XD runtime used by WiiDS 1.26 prerelease

The current release integrates this runtime into the main `io.github.maddex712.wiids` app. The canonical complete Android frontend is `source/reference/driftdroid/android`; its XD Java classes are also copied under `android/java/dev/wiids/xd` here for runtime review. There is no separate one-button XD launcher in this release. The main library, document picker, Save manager and process gates are used.

Native runtime basis: https://github.com/imyourhuckleberryponcho/Pokemon-XD-PC-Port at dd95191c360e92fe8f9283cef5a354c296521e96 and XD decompilation source at b0e9895801ea0a17b924c57e3eab86acc2691b12. Native files in `native/` are WiiDS platform/game overlays on that pinned source. They are unchanged from the released v42 runtime: main-app integration preserves every XD native library byte. The 1080p settings choice remains available. A clean-machine native rebuild is not claimed by this source overlay.

Build the Android shell using the main project's existing Gradle flags, with `wiidsVersionName=1.2.6-xd-preview.1` and `wiidsVersionCode=1206`. Stage presentation assets from `source/build/wiids-merge/assets` as in the main release tooling. Runtime libraries are not included in the source archive. Supply your own supported USA GXXE01 revision 0 disc; no disc, game assets, saves, device details or signing keys are included.
