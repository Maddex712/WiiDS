# Pokemon XD runtime used by WiiDS 1.26.2 prerelease

The runtime is integrated into `io.github.maddex712.wiids`. The canonical Android frontend is `source/reference/driftdroid/android`; its XD Java classes are also copied under `android/java/dev/wiids/xd` here for review. There is no separate one-button XD launcher in this release.

Native basis: https://github.com/imyourhuckleberryponcho/Pokemon-XD-PC-Port at `dd95191c360e92fe8f9283cef5a354c296521e96`, with XD decompilation at `b0e9895801ea0a17b924c57e3eab86acc2691b12`. Files in `native/` are platform/game overlays on that pinned source. `native/aurora/gfx/pipeline_cache.cpp` and `present_target.cpp` replace `third_party/aurora/lib/gfx/` files in that port; the corresponding Aurora MIT license is included. Those full files retain the previously accepted runtime changes as well as the new fixes. The other flat native overlays keep their existing port destinations. This remains an incremental runtime overlay; a one-command clean-machine native rebuild is not claimed.

1.26.2 adds fresh completed-packet sampling and companion-target reuse, ready-shader wake-up before disk maintenance, and bounded recovery for usable suboptimal presentation results. Timeout handling is defensive across backends; the pinned Vulkan acquire path normally waits indefinitely. These repairs do not prove that all physical gameplay stutter/flicker is resolved. The 1080p choice remains available.

Build the main Android shell with its existing flags and `wiidsVersionName=1.26.2`, `wiidsVersionCode=1209`. Stage presentation assets using the main release tooling. Runtime binaries are excluded from this source archive. Supply your own supported USA GXXE01 revision 0 disc; no game dumps, saves, signing keys or private device diagnostics are included. Host regression checks are in `tests/rendering-regressions`.
