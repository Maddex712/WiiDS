Graphics preset

Sets picture sharpness, anti-aliasing, FXAA, texture filtering, sharpening, scaling and the heat-wave effect. Change any of them and the preset becomes Custom.

Still seeing frame drops? Try a lower screen resolution: under Visuals, set Full screen type to Exclusive and choose a lower Exclusive resolution.

Performance

Sound

Picture

FSR 1 (AMD) and NIS (NVIDIA Image Scaling) render below your screen's resolution and upscale with clean edges: Quality at 67%, Balanced 59%, Performance 50%, Ultra Performance 33%, Native at full size. They set the resolution themselves, so Picture sharpness is set aside while one is on. Sharpening sets how crisp they are. Both work on any graphics card.

HDR

Checking your display…

Paper white is how bright ordinary whites, menus and text are. Peak brightness is the brightest a highlight can reach, and Highlights sets how far the brightest parts climb toward it: 0% keeps them at paper white.

Controls

Choose Change, then press a key. Esc cancels.
The buttons shown in the game's text. Original keeps the game's own; Automatic switches between keyboard and controller as you play. Remapped keys and buttons show as you set them here.

On SteamOS or a Steam Deck?

Steam Input can translate your controller into its own layout before the game sees it. That can make buttons do two things, or make the controller buttons you set here not apply. If that happens, turn Steam Input off for SMS Launcher: in Steam, open its Properties → Controller and choose Disable Steam Input. Then restart the launcher.

Playing in Desktop Mode with the launcher added to Steam as a non-Steam game is where this usually shows up.
